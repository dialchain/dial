# Validator
A validator is a form of service provider supported in the DialChain. Each participant carrying is a validator for a time window if the particcipant declaration contains the validation service record for that time window.

## Validation Protocol
The validation protocol is the list of token guarded by a validator during a ggiven time window and their last validation status.
